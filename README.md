# Customer Retention & Revenue Intelligence Platform

## Overview

This project simulates the work of a Junior Data Analyst at an e-commerce company.

The objective is to analyze customer behavior, revenue trends, and retention using SQL, Python, Power BI, and Excel.

## Tech Stack

- PostgreSQL
- Python
- Pandas
- NumPy
- Plotly
- Power BI
- Excel
- Git
